정보 수정 안내

잘못된 정보나 보완할 내용을 발견하셨나요?
수정할 내용과 근거자료를 정리해 GitHub Pull Request(PR)로 제출해 주세요.

정보 수정에는 근거자료가 반드시 필요합니다.

제안한 내용을 확인할 수 있는 출처와 해당 부분을 함께 적어 주세요. 근거가 없거나 확인할 수 없는 경우에는 정보 수정을 반영하기 어렵습니다.

수정 요청에 포함할 내용

  • 수정 대상: 지식 제목, 항목 ID 또는 해당 페이지 링크
  • 수정 전 · 후: 현재 내용과 제안하는 내용을 구체적으로 작성
  • 수정 이유: 어떤 부분이 잘못되었는지, 무엇을 보완해야 하는지 설명
  • 근거자료: 출처 제목, 작성자·발행기관, 발행일, 원문 URL
  • 확인 위치: 관련 문장, 문서 쪽수·절 또는 영상 시간과 그 근거가 수정을 뒷받침하는 이유

어떤 근거자료가 필요한가요?

공식 문서, 원본 기록, 연구 논문, 공공기관 자료처럼 원문을 확인할 수 있는 자료를 우선해 주세요. 보도자료나 기사를 사용하는 경우에도 원출처와 보도 시점을 함께 확인해 주세요.

개인적인 추측이나 출처 없는 이미지, AI 답변만으로는 사실을 검증하기 어렵습니다. 자료가 확인해 주는 범위와 아직 확인되지 않은 부분을 구분해 작성해 주세요.

PR로 제출하는 방법

  1. 아래 버튼으로 GitHub 저장소를 열고, 로그인한 뒤 저장소를 Fork합니다.
  2. 새 브랜치에서 해당 내용을 수정합니다. 데이터 수정이 어렵다면 수정 제안과 근거자료를 담은 Markdown 파일을 research/corrections/ 폴더에 새로 추가해도 됩니다.
  3. 변경사항을 커밋하고 원본 저장소의 기본 브랜치를 대상으로 Pull Request를 생성합니다.
  4. PR 본문에 수정 대상, 수정 전·후, 이유, 근거자료를 작성해 제출해 주세요.

제출된 내용은 근거자료 검토 후 반영 여부를 결정합니다. PR 제출만으로 웹페이지가 자동 수정되지는 않으며, 추가 자료를 요청할 수 있습니다.
